# 稿藏

把散落的稿件放在一起读，保留每次修改和阅读后的判断。

稿藏是一款本地文章整理与批注工具。可以按主题收拢不同稿次，给单稿命名，在正文中选择词句写批注，也可以用人物与CP圆点标签查找文章。

当前为早期测试版，源码采用MIT许可证。首发计划提供Mac（Apple芯片、Intel）及Windows x64安装包。Windows构建与实际安装结果以该平台验证记录为准，不因存在打包配置就视为已通过。

## 使用

- 打开后有两份虚构示例。点击“导入文章”，选择UTF-8 TXT或Markdown，放到新主题或既有主题中。Markdown暂以纯文字显示。
- 每份文章不超过2MB，一次不超过30份；首版资料库正文总量不超过32MB、最多3000稿。导入文件不会改动原文件。
- 文章、稿次、分类、角色颜色、筛选、评价和行内批注都保存在本机；应用不提供账号登录，不上传正文。
- 右上“导出备份”包含当前页面的正文及整理记录，保存失败时也可以导出尚未保存的改动。换电脑时使用“导入备份”。已有本机记录优先，导入前自动留存恢复副本。同一稿件标识遇到不同正文会拒绝导入。
- 自动保存采用一份轮换副本；导入和恢复操作保留最近10份操作前副本。异常退出后，可选择恢复上次未保存的记录，或先将它导出再继续阅读。
- 退出时先完成正在写的编辑框，程序会尝试完成保存。没有显示保存成功时，请保留输入并导出备份。

Mac资料默认位于当前用户的`Library/Application Support/io.gaocang.desktop/library`；Windows位于当前用户的`AppData/Roaming/io.gaocang.desktop/library`。安装目录与资料目录分离；更新程序不需要删除资料。

AI讨论和云端自动同步不属于这一版。不同电脑之间可手动导出/导入完整备份。

## 开发与构建

开发需要Node24或更新的兼容版本；普通用户将使用自带运行时的安装包。

```sh
npm ci
npm test
npm run check:public
npm start
```

在对应系统上打包：

```sh
npx electron-builder --mac --arm64 --publish never
npx electron-builder --mac --x64 --publish never
npx electron-builder --win --x64 --publish never
```

推送到main或手动运行Actions工作流会生成测试安装包，不自动发布Release。在仓库的Actions中打开对应运行记录，下载Artifacts内的`gaocang-mac-arm64`、`gaocang-mac-x64`或`gaocang-win-x64`。当前没有配置开发者发行证书或平台公证，不宣称已完成受信任发行；发布前须核对各平台的安装要求。
